# B1-1 동료평가 시나리오

## 1. 학습
- SSH 보안 (포트 변경, Root 차단)
- 방화벽 (UFW, 최소 권한)
- 계정/그룹/ACL (역할 기반 접근 제어)
- 셸 스크립트 (monitor.sh)
- cron (자동 실행)

## 2. 고찰
- "보안은 편의성과의 균형" — 모든 포트를 막으면 안 됨
- "자동화는 필수" — 사람이 매분 확인할 수 없음

## 3. 시도
- Docker 기반 Ubuntu 22.04 컨테이너 구축
- SSH 20022, UFW 20022/15034, 계정 3개+그룹 2개
- monitor.sh: 프로세스/포트/CPU/MEM/DISK + 로그
- cron 매분 실행

## 4. 수정
- 권한 770 → 역할별 차등 (공유 vs 보안)
- monitor.sh 로그 포맷 표준화

## 5. 선택과 선정
- UFW vs firewalld: UFW 선택 (간단, Ubuntu 기본)
- 770 vs 750: 상황별 차등 (공유=770, 보안=770+그룹제한)

## 6. 트러블슈팅
- cron 안 돌아감 → 권한 + 그룹 멤버십 확인
- 앱 부트 실패 → 환경변수 누락 확인
